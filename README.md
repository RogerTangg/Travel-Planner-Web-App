# 🌍 Travel Planner Web App

**智慧旅遊行程規劃工具**

</div>

## 功能特色

- **AI 景點分析** - 輸入景點名稱，自動取得詳細資訊、座標與建議停留時間
- **多行程管理** - 支援建立多個旅行計畫，資料自動儲存於本地
- **智慧排程** - AI 根據地理位置與旅遊邏輯，自動分配待安排景點
- **拖放編排** - 直覺化的拖放操作，輕鬆調整行程順序
- **互動地圖** - 即時顯示所有景點位置，點擊可飛行定位
- **檔案匯入** - 支援上傳 .txt、.csv、.md 檔案，AI 自動提取景點

## 執行專案

**前置需求：** Node.js

1. 安裝依賴：
   ```bash
   npm install
   ```

2. 設定 API Key：
   在 [.env.local](.env.local) 中設定 `GEMINI_API_KEY`

3. 啟動開發伺服器：
   ```bash
   npm run dev
   ```
